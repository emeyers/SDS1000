# Articles

### Transitioning to Base R

A guide for students graduating from SDS1000 who want to analyze data
using standard R without relying on the SDS1000 package.

- [Transitioning to Base R: Simulation and Data
  Summaries](https://emeyers.github.io/SDS1000/articles/transitioning-simulation.md):

  Part 1 of 2. Covers do_it(), get_proportion(), rflip(), rroll(),
  shuffle(), and resample_pairs() and their base R equivalents.

- [Transitioning to Base R: Inference and
  Visualization](https://emeyers.github.io/SDS1000/articles/transitioning-inference.md):

  Part 2 of 2. Covers ptail(), cnorm(), ct(), distribution plots, and a
  complete worked example using only base R.

- [Transitioning to Base R: Theory-Based Hypothesis
  Tests](https://emeyers.github.io/SDS1000/articles/transitioning-theory-tests.md):

  Part 3 of the transitioning series. Covers t.test(), cor.test(),
  aov(), chisq.test(), and lm() as complete base R replacements for the
  SDS1000 wrapper functions.

- [SDS1000 to Base R Cheat
  Sheet](https://emeyers.github.io/SDS1000/articles/transitioning-cheatsheet.md):

  A printable one-page summary of every SDS1000 function and its base R
  equivalent. Use File \> Print (or Ctrl/Cmd + P) to save as PDF.

### Class Summaries

Reference guides showing how to run each type of analysis covered in
S&DS 1000 using base R.

- [Parametric Confidence
  Intervals](https://emeyers.github.io/SDS1000/articles/class-summary-parametric-cis.md):

  A reference guide covering every parametric confidence interval from
  S&DS 1000: one proportion, one mean, difference of two means, and
  regression slope.

- [Parametric Hypothesis
  Tests](https://emeyers.github.io/SDS1000/articles/class-summary-parametric-tests.md):

  A reference guide covering every parametric hypothesis test from S&DS
  1000: one and two proportions, multiple proportions (chi-squared), one
  mean, two means (independent and paired), multiple means (ANOVA),
  correlation, and simple linear regression.

- [Randomization (Bootstrap) Confidence
  Intervals](https://emeyers.github.io/SDS1000/articles/class-summary-randomization-cis.md):

  A reference guide covering every bootstrap confidence interval from
  S&DS 1000: one proportion, one mean, difference of two means, and
  regression slope.

- [Randomization Hypothesis
  Tests](https://emeyers.github.io/SDS1000/articles/class-summary-randomization-tests.md):

  A reference guide covering every randomization (simulation-based)
  hypothesis test from S&DS 1000: one proportion, two proportions,
  multiple proportions, one mean, two means, more than two means,
  correlation, and simple linear regression.
