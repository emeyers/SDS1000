# Get the package name and version number

Returns the name of the package and the version number. This is useful
to check that one is using the most recent version of the package in
case the package is updated in the middle of the semester.

## Usage

``` r
get_version()
```

## Examples

``` r
 # Download the first homework file
 get_version()
#> [1] "SDS1000: version 0.2026.3"
```
