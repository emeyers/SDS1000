# Generate a random sample of sprinkle colors

This function generates a fictional sample of data of sprinkles.

## Usage

``` r
rsprinkles(n)
```

## Arguments

- n:

  The sample size.

## Examples

``` r
 # Generate a sample from 10 sprinkle colors
 rsprinkles(10)
#>  [1] red    pink   orange red    white  green  pink   white  orange green 
#> Levels: green orange pink red white yellow
```
