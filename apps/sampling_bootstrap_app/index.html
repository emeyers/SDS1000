Sampling Distribution Demonstration

A demonstration of the relationship between a population, a sample, a sampling distribution, and a bootstrap distribution. Changing the sample size (or clicking “Draw a new sample”) creates a new example sample and a new bootstrap distribution.

Check “Display Bootstrap Distribution” to show the bootstrap distribution created from the example sample.
